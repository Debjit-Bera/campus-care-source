Features

Everything needed to resolve issues, in one place

Simple for students, powerful for administrators.

Easy complaint submission

Describe the problem, pick a category and priority, add a photo and get a unique complaint ID instantly.

Real-time tracking

Follow every complaint through Pending, In Progress and Resolved with a full status history.

Admin remarks

Administrators post updates so students always know what is being done and when.

Support similar issues

Tap “Me too” on existing complaints to show how many students are affected, with no duplicates.

Analytics dashboard

Category-wise and status-wise charts help admins spot problem areas and prioritise work.

Instant notifications

Get notified when a complaint is submitted, updated or resolved. Nothing slips through.

How it works

From problem to solution in four steps

A transparent journey every student can follow.

1. Register

Create a free student account in under a minute.

2. Report

Submit the issue with details, priority and an optional photo.

3. Admin acts

The facilities team reviews, updates status and adds remarks.

4. Resolved

Track progress and get notified when it is fixed.
